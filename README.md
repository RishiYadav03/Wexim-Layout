# Wexim-Layout

WEXIM_LAYOUT typically refers to a modern, multipurpose HTML template or website layout designed with HTML, CSS, and Bootstrap. It is commonly used for creative agencies, startups, personal portfolios, or business websites.

WEXIM_LAYOUT is a clean, responsive, and feature-rich web layout built using HTML5, CSS3, and Bootstrap (version 5). It is designed with a focus on elegant design, modern UI components, and cross-device compatibility.


✨ Key Features

1] Hero Section: A prominent, full-width banner often featuring animated text, background images, or videos to catch attention.

2] Navigation Bar:

   2.1) Sticky or transparent navbar.
   
   2.2) Smooth scrolling to different sections of the page.
   
3] About / Services Section: Grid or column layouts showcasing services or personal/professional information.

4] Portfolio / Gallery:

   4.1) Filterable image or project grid.
   
   4.2) Modal popups or lightbox integration for image previews.
   
5] Team Section: Cards or profile blocks to introduce team members with hover effects.

6] Testimonials: Carousel sliders using Bootstrap or third-party JS libraries to show client feedback.

7] Contact Form: Styled input fields.

8] Footer:

   8.1) Social media icons.
   
   8.2) Copyright.


🛠️ Technical Stack

1] HTML5: Semantic structure and content.

2] CSS3: Custom styling, animations, and hover effects.

3] Bootstrap: Grid system, responsive design, and prebuilt components (buttons, navbars, modals, etc.).

4] Font Awesome / Icon Libraries: For scalable vector icons.


🎨 Design Style

1] Flat design with smooth gradients or background videos.

2] Use of white space for clean layout.

3] Vibrant color palette.

4] Animations triggered on scroll ( Animate.css is used).
